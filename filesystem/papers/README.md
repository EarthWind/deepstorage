# 分布式文件存储论文清单

本目录收录 2000 年至 2026 年 8 月分布式文件存储领域的重要论文清单，作为进入该领域的阅读地图。

| 文档 | 内容 |
|------|------|
| [essential-papers-2000-2026.md](essential-papers-2000-2026.md) | 核心必读 25 篇 + 按主题分类的完整清单（生产系统、元数据、数据路径、复制与共识、纠删码、HPC/AI 存储、客户端、新硬件、可靠性实证）+ 按年份索引 |

## 与 `project/papers/` 的关系

- 本目录是**清单**：只给出论文、机构、会议和一句话定位，跨度 2000–2026.08。
- [`../project/papers/`](../project/papers/README.md) 是**详解**：只覆盖 2020 年之后的论文，每篇有内容摘要、出处链接与设计启示。
- 清单中 2020 年后的条目均可在详解目录中找到对应小节。

## 建议阅读路径

1. 先按 [核心必读 25 篇](essential-papers-2000-2026.md#1-核心必读-25-篇) 的顺序建立整体框架。
2. 根据关注点进入对应主题节：设计元数据服务看第 3 节，设计数据路径与冗余看第 4、6 节，做可靠性工程看第 10 节。
3. 需要结合具体系统时，用第 11 节的对照表跳到本仓库对应的系统调研。
